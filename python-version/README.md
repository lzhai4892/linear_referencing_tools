# Internal LRS Toolkit (Python)

Optional reference copy of the original FastAPI / pandas app (`lrs_app` + `lrs_tools`) from `aadt-review-for-fl-source-book`.

**You can delete this whole `python-version` folder** if you are using the JavaScript app in `../js-version/`.

This copy does not include that project's `pyproject.toml` or virtual environment. To run it you need geopandas, FastAPI, and uvicorn, then from this folder:

```bash
python -m lrs_app
```

Or use `run_lrs_app.bat` only if `uv` and a project environment are already set up here.
