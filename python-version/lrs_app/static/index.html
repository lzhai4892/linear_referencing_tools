Internal LRS Toolkit

Local-only tool for joining, breaking, and merging linear-referencing event tables. Nothing is published to the web.

127.0.0.1

Join two line files and break at mileposts

Overlays a target event table onto another using roadway ID + BMP/EMP. Gaps stay on the target when join is left.

Merge lines when mileposts connect

Dissolves adjacent segments that share attributes. Default requires current BMP to match previous EMP within 0.0001 mile.

Locate points on line events

Keeps point rows whose LOCATION falls between a matching roadway’s BMP and EMP.

Clip event mileposts onto a route layer

Cuts route geometries to each event BMP–EMP. Write .gpkg or .shp so geometry is saved.

Export geometry as Shapefile or GeoJSON

Provide a source line layer that already has linear referencing. Pick the segment ID, begin milepost, and end milepost fields. Optionally clip an event table onto that layer, then write .shp or .geojson.
