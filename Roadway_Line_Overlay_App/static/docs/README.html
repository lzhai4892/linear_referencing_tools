GeoCorridor Studio Documentation

Generalized Roadway Line-to-Line GIS Corridor Overlay Engine for Transportation Planning.

1. Mathematical Methodology

GeoCorridor Studio evaluates linear physical alignment between a Destination (Target) Layer and a Reference Roadway Layer using localized along-corridor matching:

  • Corridor Buffer: Default 300 ft buffer around reference centerlines.
  • Minimum Overlap: Overlap length ≥ 300 ft and overlap ratio ≥ 30% of target length.
  • Undirected Local Bearing: Bearings are evaluated over a 500 ft window centered on the overlap midpoint. Direction is evaluated modulo 180° / 90° to handle opposing digitizing directions.
  • Strong Fallback: Overlap ≥ 75% and perpendicular distance ≤ 30 ft retains curving mainline segments.

2. Supported Input Formats

  • Zipped Shapefiles (.zip) containing .shp, .dbf, .shx, and .prj.
  • GeoJSON (.geojson / .json)
  • KML (.kml)
  • GeoPackage (.gpkg)
  • CSV (.csv) with WKT geometry or coordinates.

3. Attribute Transfer & Expressions

You can choose single reference columns or compose templates such as {ITEMSEG} - {high_yr_ph} or {ROADWAY} (MP {BEGMP}-{ENDMP}).
